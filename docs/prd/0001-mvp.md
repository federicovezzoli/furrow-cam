# PRD-0001: MVP, 2D vector → G-code for hobby CNC routers

- **Status:** Draft
- **Author:** Federico Vezzoli
- **Created:** 2026-10-08

## Problem

Hobbyists and small shops with CNC routers need to turn 2D designs (SVG/DXF) into G-code. Existing options are usually one of these:

- **Commercial desktop apps**: cost money, one OS only, closed.
- **Open source desktop tools**: capable but often dated UX and painful installation.
- **Web tools**: convenient, but often cloud-locked, unmaintained, or limited in operations.

There is room for a modern, open, browser-based 2.5D CAM that "just works" for the common cases, and keeps your projects and tool library available wherever you log in.

## Users

- **Primary:** hobbyist with a GRBL-class router (Shapeoko, X-Carve, 3018, OneFinity, LowRider, etc.) cutting wood, plywood, MDF, plastics.
- **Secondary:** makerspace members, small sign/furniture shops, educators.

## Goals

- A user can go from an SVG/DXF file to a safe, correct G-code file in a few minutes.
- Toolpaths are visually previewed before export.
- Projects, tool library and machine settings are saved to the user's account and available on any device.

## Non-goals (MVP)

- 3D surfacing / freeform models (STL, STEP).
- Built-in CAD / drawing tools beyond trivial edits.
- Machine control / sending G-code (handled by existing senders such as UGS, CNCjs, gSender).
- Mills and metal machining (Furrow CAM targets CNC routers only).
- Multi-axis, lathe, laser-specific or plasma-specific features.
- Offline use.
- Collaboration, sharing projects between users.

## Requirements

| ID | Requirement | Priority |
| --- | --- | --- |
| R1 | Import SVG | Must |
| R2 | Import DXF (lines, arcs, polylines, circles) | Must |
| R3 | Define stock: size, thickness, XY/Z origin | Must |
| R4 | Tool library: end mills (diameter, flutes, feeds/speeds) | Must |
| R5 | Profile operation: inside / outside / on-line, multiple depth passes | Must |
| R6 | Holding tabs on profiles | Must |
| R7 | Pocket operation (offset clearing) | Must |
| R8 | Drill operation (circles / points) | Should |

| R13 | Save / load projects to the user's account | Must |

## User flow

1. Log in → open an existing project or create a new one → set units, machine and stock.
2. Import SVG/DXF → geometry appears on the stock.
3. Select shapes → add operation (profile / pocket / drill) → pick tool, depths, options.
4. Preview toolpaths; adjust.
5. Project auto-saves to the account. Export G-code → run with the user's usual sender.

## Success criteria

- A test part (outside profile with tabs + pocket + holes) cut on a GRBL machine with **zero manual G-code edits**.
- Generated G-code passes validation in at least one common G-code viewer/simulator.
- Toolpath generation for a typical hobby file (< 500 paths) completes in under 2 s on a mid-range laptop.
