Zero picker in the stock properties (PRD-0002 Z2, Z4, Z9, Z10): a 3×3 grid puts the XY zero on any stock anchor (radio group, arrow keys move around the grid as laid out), **Custom** reveals unit-aware X and Y fields measured from the stock's bottom-left corner and pre-filled with the current zero so it doesn't jump, and a selector chooses the Z zero (stock top or machine bed). Each change is one undo step.
