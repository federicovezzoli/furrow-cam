# Bundled fonts

The fonts text items use (PRD-0010 T4), shipped unmodified with the workspace so the web and desktop apps lay text out without loading anything from the internet. Each is listed in `src/lib/fonts.ts` with the id projects store.

| Font | Id | Kind | Source | Licence |
| --- | --- | --- | --- | --- |
| Archivo Black | `archivo-black` | Sans | [google/fonts](https://github.com/google/fonts/tree/main/ofl/archivoblack) | SIL OFL 1.1, [ArchivoBlack-OFL.txt](ArchivoBlack-OFL.txt) |
| Arvo | `arvo` | Serif | [google/fonts](https://github.com/google/fonts/tree/main/ofl/arvo) | SIL OFL 1.1, [Arvo-OFL.txt](Arvo-OFL.txt) |
| Pacifico | `pacifico` | Script | [google/fonts](https://github.com/google/fonts/tree/main/ofl/pacifico) | SIL OFL 1.1, [Pacifico-OFL.txt](Pacifico-OFL.txt) |
| Relief SingleLine CAD | `relief-singleline` | Single stroke | [isdat-type/Relief-SingleLine](https://github.com/isdat-type/Relief-SingleLine/tree/master/fonts/open_ttf) | SIL OFL 1.1, [Relief-OFL.txt](Relief-OFL.txt) |

Arvo has a Reserved Font Name: a modified copy must be renamed.
