# @furrow/download

## 0.2.0

### Minor Changes

- The desktop app now comes as a pacman package for Arch Linux, at `download.furrow.cam/linux-pacman`. It adds Furrow CAM to the app launcher and opens `.furrow` files. ([#248](https://github.com/federicovezzoli/furrow-cam/pull/248))

## 0.1.0

### Minor Changes

- The desktop app now has stable download links, such as `download.furrow.cam/mac-arm64`, that always point at the newest installer for each system. ([#217](https://github.com/federicovezzoli/furrow-cam/pull/217))
